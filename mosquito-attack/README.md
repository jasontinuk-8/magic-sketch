# Mosquito Attack Web 2.3 — Inventory & Spray

- Pick up electric racket (10 seconds) or insect spray (15 seconds).
- Up to 3 inventory slots at the bottom; pick-ups fill empty slots, full inventory cannot collect more.
- Tap a slot to equip; tap the active slot to store it. Countdown runs only when equipped, and pauses while stored.
- Press and hold and sweep to attack; continuous electric hum or spray hiss while holding, separate hit sound when a mosquito is killed.
- After Game Over, tap Play Again to return to mosquito limit selection (24/50/80/100), then Start Game.
- Everything runs locally in one HTML file; no dependencies.

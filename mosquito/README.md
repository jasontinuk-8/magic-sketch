# Mosquito Attack Web 2.1 — Sweep Swatter

Based on Web 2.0. Electric swatter pickup still appears randomly and lasts 10 seconds. During the power-up, press and hold the canvas, then drag a finger or mouse to sweep through mosquitoes continuously. The hit zone follows the pointer, including between sampled pointer positions, and checks for mosquitoes flying into a stationary held racket. Electric sound, flashing, vibration (where supported), splats, score, and leaderboard remain. Ordinary swatting remains tap-only.

Open index.html in a browser. Audio requires user interaction. iOS Safari does not generally support web vibration.
